## 交易标的与结算币

BTC、ETH、SOL；保证金和交易结算为USDC。CARDBOARD是权益/激励资产，不能直接列为已开通合约标的。 [完整清单与来源范围](../markets.zh-CN.md)。

## 身份、运营状态与关系

Cardboard 是 Solana 上以 USDC 结算的 BTC、ETH、SOL 合成长短仓产品，文档支持1—1000倍、每单名义金额上限1000万美元。10月25日版条款自述运营方为 **Attractor Labs, Inc.**；已读材料未确立注册法域、总部、实名创始人或履历。限制哪些国家访问，不能用来推断团队所在地。[C001、C011]

它与 Papertrade 有很强的**机制相似性**：用户对赌 house、盈利可能排队、亏损铸造参与分红的代币。外部评论中的“fork”不是代码同源证据；本轮未找到可直接确认的官方借鉴声明或代码谱系，因此不写成已经证明的代码分叉。

官方账号的第三方镜像有10月18—27日的运营更新，含 analytics、builder、SDK 等；镜像不是直接读取 X，也不能证明首笔主网交易。预告、beta、实盘启动的精确时刻均保留未知。当前API报告交易未暂停、存在持仓和累计活动，属于供应商层面的运营证据，不能倒推最早上线时间。[C014—C017]

## 产品机制与业务经济

| 项目 | 已取得描述与限制 |
|---|---|
| 定价与执行 | 每个逐仓仓位面对 house；开平仓使用已接受买卖报价的中点。新仓要求报价新鲜，停更时平仓/清算可能使用最后接受价格。已读页面未确立底层报价供应商身份；无周期资金费。[C002、C009] |
| 仓位调整 | 不能追加/取出保证金、改杠杆或部分平仓；加敞口需另开一仓。[C002] |
| 盈利支付 | 深度/敞口曲线在开仓时锁定盈利敞口，多空容量分开；随后还有锁定的 deadband、盈利费、平仓名义额收费。拆单不能凭空创造容量。[C003—C004] |
| 亏损与清算 | 逆向价格损失减少逐仓保证金，爆仓损失整笔保证金。house 从自身所得中划出的亏损侧费用不是额外价格损失，但平仓收费仍可减少返还额。清算专页本次未成功返回，现行缓冲值未知。[C004—C005] |
| 队列 | 现金保证金的剩余部分返还可用余额；无钱支付的利润按 FIFO 排队，可部分支付，无承诺日期。可选的欠款抵押模式可能继续损耗或消灭尚未兑现的债权。[C006] |
| 亏损激励 | 合格逆向价格亏损、含爆仓整笔保证金，可产生待领取 CARDBOARD；仅平仓收费造成的负收益不符合条件。文档称零初始供应，house追踪值低于100万美元时每美元合格亏损铸100枚，之后按累计进度递减。它不是亏损退款。[C007] |
| 分红与收入 | 可收取盈利/亏损费的一半进入质押及推荐奖励预算，另一半归费用接收方；名义额平仓收费归 house。超过现行阈值的合格盈余也可分配，队列优先。质押按份额分配，目前无冷却期。[C008] |
| Builder | 用户钱包或会话授权；默认附加费为基础费用的10%，上限25%，不是订单名义额的10%/25%。[C010] |

本轮配置API报告：`max_leverage=1000`、`deadband_ppm=0`、`round_trip_fee_ppm=200`（0.02%，即2bp）、`trading_paused=false`。这些是采集时的**供应商配置**，没有认证为链上参数。文档的现行参数表存在动态占位符，旧帖的0.4bp费用或0.2bp deadband不能替代本轮读数。[C015]

官方文档允许运营者暂停新仓、限制/退出市场、冻结账户及按明确价格关闭特定仓位。冻结可阻止自主平仓、充提及奖励操作，同时仍可清算。文档称中继延迟200ms，清算/平仓优先；本轮未验证程序升级权限及部署二进制与源码的对应关系。[C009]

## 业务体量证据与缺口

公共[analytics接口](https://cardboardtrade.xyz/v1/analytics?range=1d)提供累计 `stats.volume`、`trades`、`users`，另有三个市场 `*_volume_24h`、OI、在仓保证金、LP现金、treasury和欠付。**`range=1d` 不代表 `stats.volume` 是一日成交量。**本轮读数为75,008笔、1,388用户，但去重及统计人群定义未确认。`lp_cash` 不等于 treasury，更不等于用户余额。[C016]

响应没有明确业务截止时间，应保留 null，抓取时间单列。system接口有索引/slot新鲜度，但没有将analytics绑定到规范区块哈希。累计历史完整性、刷量过滤、真实人数、费用收入勾稽和排队时长均未独立验证。原始活动明细保持私有，对外仅发布聚合字段。[C016—C017]

C001—C018 对应元数据中的 `EVD-COMP-CARDBOARD-001`—`018`；其中记录成功/失败请求、SHA-256及读取限制。本轮共18次低频公共GET，无登录或钱包操作。
