## 交易标的与结算币

BTC、ETH、SOL、ZEC、NEAR、XMR、HYPE；保证金和交易结算为USDC。标的清单不解决两个接口的杠杆上限冲突。 [完整清单与来源范围](../markets.zh-CN.md)。

## 身份、时间与关系

官方前端链接 `@rektradefun` 及 Ember；API配置为HyperEVM chain999、USDC保证金。本轮经第三方镜像读到官方账号10月22日称“live on HyperEVM”；Ember的镜像公告称其界面与Rektrade使用**同一组合约、同一keeper**，所以不能当两家独立交易场所相加。实名法律运营方、经过核实的创始人/履历及所在地均未知。[R001—R004]

Rektrade具备house对手盘、赔付队列、亏损发行收入参与代币的特色组合，属于Papertrade的**强机制相似项目**。镜像有与PAPER比较的文字及第三方fork生态清单，但不等于承认代码借鉴或验证过的代码fork。精确首笔主网交易、部署时刻、独立beta/预告时刻均未验证；10月22日是通过镜像取得的官方上线说法。[R003]

## 机制与现行配置差异

| 项目 | 本轮证据 |
|---|---|
| 市场和杠杆 | 当前 `/api/markets` 含BTC、ETH、SOL、ZEC、NEAR、XMR及 **HYPE**，各上限1000倍；前端描述固定1000倍开仓。不能用早期六市场帖子定义现状。同期 `/api/config` 的市场列表仍给SOL500倍、ZEC/NEAR/XMR200倍，与 `/api/markets` 冲突，固定1000倍不是本研究验证过的执行保证。[R002、R004、R008] |
| 价格 | 内嵌文档笼统称HyperCore BBO midpoint预编译。当前API却报告BTC/ETH/SOL用 `bbo`，ZEC/NEAR/XMR用 `oracle`，HYPE用 `mark`。这构成重要的说明/配置冲突，不能说全市场按BBO结算。API中的Hyperliquid `dayVolume`是底层市场量，不是Rektrade量。[R002、R008] |
| 仓位和清算 | 文档为逐仓固定保证金，不能追加、改杠杆或部分平仓；当前配置最短持仓10秒。爆仓损失全部保证金，报告缓冲5bp，1000倍约反向0.05%爆仓。文档称无订单簿、资金费或名义额交易费。[R002、R004] |
| 盈利成本 | 先deadband、非对称impact，再盈利费及win tax。API报告0.2bp deadband（`deadbandDiv=50000`）、impact基础27.3%、盈利费5%、win tax20%；阶段不同，不能直接相加成原始利润的25%费用。[R002、R004] |
| 亏损/入金成本 | 用户价格损失以保证金为限，house在无人排队时可从自身所得划出亏损费。API报告亏损费5%、入金税5%、最低入金5USDC。入金税和名义额交易费经济含义不同。[R002、R004] |
| House与队列 | 文档称LP从空池靠亏损启动；现金保证金剩余部分平仓返还，无钱支付的利润FIFO排队，现金足够覆盖队头后偿付，排队时损失优先供给队列而不收相关费用。API将可用现金、权益、负债及队列分开。[R002、R005] |
| 收入参与 | 已实现亏损发行REKT，上限2100万；质押分可收费用及超过阈值的LP盈余。API当前质押分成30%、盈余阈值50万USDC。这些是业务条款，不是收益预测。[R002、R004] |
| 权限 | 内嵌文档称无代理/升级，owner可在硬边界内改参数、暂停/退出市场，且仅在队列为空时提取无负担house现金；guardian可暂停/退出。会话密钥可交易而不能提币/质押/领取。以上为未审计的官方描述。[R002] |

另有两处不能合并成永久规则：内嵌文档写21→1逐日减1的铸币日程；当前house API则报告**起始14.9、每日减0.6、下限1、第7日11.3**，另有质押加成。配置还暴露 `mintHouseBps=2000`，具体部署分配语义尚未复现。内嵌文档称代币市场为Uniswap v4，当前API却标HyperSwap V2；本研究不分析币价，仅将差异用于版本可靠性判断。[R002、R004—R005]

## 业务体量证据

公共[stats接口](https://rektrade.fun/api/stats)有累计成交量、交易/交易者数、亏损、支付给赢家、用户余额、在仓保证金、费用和质押分配。本轮报告 **1449笔/52交易者**，house接口另有现金/队列账。人群去重、真人数、历史完整性及刷量过滤未知。前端金额格式为6位USDC精度，不能套用代币精度；累计 `volume` 不应标成24小时量。[R002、R005—R006]

`/api/stats.at`是供应商提供的Unix秒业务时间，house有索引高度但无规范区块哈希。抓取时间与业务时间分列。单次零队列/零持仓不能证明历史偿付能力或没有需求。本轮无个人钱包查询、合约执行、安全验证或全事件回放。status接口发生传输失败，不能据此断言整站宕机。[R005—R007]

R001—R008 对应 `EVD-COMP-REKTRADE-001`—`008`。本档案采集共8次低频公共GET，含上述失败；元数据记录UTC及成功capture的SHA-256，原始含账户/身份字段部分保持私有。
