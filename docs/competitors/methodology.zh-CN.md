# 证据规范与业务指标口径

[English](methodology.md) · [综合报告](README.zh-CN.md)

## 证据层级与产品身份

读到资料只能支持“资料这样说”，不能直接证明部署执行。本专题区分**已验证的观测、来源自述、尚未独立验证、无法取得**。独立复算只针对指定输入和计算，不表示完整协议复现。

每个项目保持独立身份。官方承认借鉴、可验证代码fork、机制相近、路由/集成、相邻对照是不同关系；高杠杆或付款队列相似不能证明复制代码。链、预言机或分发伙伴不自动成为产品发行方、出资方或法定运营方。姓名、地域、融资和日期未知时保持未知。

候选池最多12个，报告最多六个竞品，Papertrade另列基准。通用模拟交易、同名代币、机器人、仪表盘和财库产品不纳入直接竞品。独立底层业务与路由业务分别记录。

## 时间与覆盖范围

分别记录采集时间、业务数据时间、发布日期和版本。只有日期时不自动补午夜。预告、公开beta、首笔实盘、部署、配置上线时间和升级是不同事件。镜像和复述同一公告的媒体仍有依赖关系。

优先比较以完整UTC小时结束的 `[start,end)` 窗口，前提是两端历史状态齐备且已最终确定，或事件覆盖完整。来源只有滚动窗口、自然日或累计值且无法确定边界时，保留原标签。不插值、不把上线日数字年化、不把缺桶补零、不把起点未知的累计值叫“上线至今”。北京时间为UTC+8。

HTTP响应新鲜不代表业务数据新鲜。不同截止时间的接口不能拼成同时点资产负债表。合约不升级也可能改参数，因此机制结论保留文档、前端和API版本边界。

## 指标字典

| 指标 | 定义与必要区分 |
|---|---|
| 名义成交量 | 通常为保证金乘杠杆的风险敞口，说明开仓、主动平仓、清算和双边怎样计数；不是实际入金。 |
| 交易笔数 | 明确按开仓、平仓或成交计数，不合并不同事件口径。 |
| 活跃钱包 | 指定窗口和覆盖范围内满足条件的唯一交易钱包；累计用户、新增钱包不同，钱包不等于真人。 |
| TVL | 保留来源资产与账户范围，可能包含用户余额和保证金，不能改名为庄家本金。 |
| 庄家资金 | 区分账面LP、可用现金、资金库、隔离保证金、Reserve和欠款；重叠账本不相加。 |
| OI | 未关闭的交易者多头加空头名义额，不把庄家对手侧再加一次。 |
| 费用 | 按来源定义，分别研究盈利费、平仓费、builder费、交易利润和分红；费用不等于全部交易成本。 |
| 付款队列 | 某时点未付债权；金额、笔数、等待时间和偿付规则分别记录。单次为零不证明长期无欠款或未来偿付能力。 |
| 交易者PnL | 说明费前/费后、已结算/已付、排队债权及非现金奖励是否计入。 |
| 排行榜 | 明确窗口、排序、筛选、分页和样本；头部账户不能推导总体、胜率或留存。 |

本次不发布跨项目总量：覆盖范围和计数定义不同，路由还可能重复计算Papertrade业务。亏损激励和质押属于经济机制研究，不分析币价、市值或投资价值。

## 记录与采集

`research/competitors/protocol.json` 固定范围和采集政策，`sources/*.json` 记录原子来源支持与依赖，`snapshots/*.json` 保存审阅后的数值，`milestones.json` 记录实际进度。数值必须有单位，未知使用null并解释。来源无业务时点时 `as_of` 保持null，不能用 `retrieved_at` 替代。

原始捕获、响应字节和交接文件放在忽略的私有目录。SHA-256只证明字节一致，不证明真伪、来源真实性或再分发权。公开元数据不含原始字节时，不能宣称仅靠公开仓库即可完整历史回放。公开内容采用原创概括、必要最小摘要和审阅后的聚合元数据，不建立个人身份关联。

最小工具仅使用固定公开GET，无凭证、不跟随重定向，每轮最多60请求、请求起始至少相隔一秒、30秒超时、响应上限2MB。401/403/429停止采集。无适配器项目返回blocked且不发请求。研究不包含钱包操作和链上变更。
